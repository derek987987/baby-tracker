# Quickstart: Baby Tracking App

## Overview
A native iOS application built for tired parents to easily track baby care events with one-handed UI. The project is structured as a standard Xcode project, facilitating native compilation and testing.

## Getting Started
1. Open `baby-tracker.xcodeproj` in Xcode.
2. Select the `baby-tracker` target.
3. Build and run on an iOS 18 simulator or device.
4. Run tests from within Xcode using `Cmd+U`.

## Core Workflows
- **Log an event**: Tap one of the primary care buttons (Feeding, Diaper, Sleep) on the bottom-anchored dashboard.
- **View timeline**: Scroll the main dashboard vertically to see chronological entries for today.
- **Check daily totals**: Navigate to the summary view to see sleep duration and total feeding volume for the current day.
