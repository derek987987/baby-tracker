# BabyTracker

A minimalist, high-performance iOS application for tracking newborn daily routines.

## Features
- **Smart Quick-Logging**: Log feedings, diapers, and sleep with a modern, gesture-driven flow.
- **Multi-Baby Support**: Track multiple children and switch between them seamlessly.
- **Detailed Analytics**: View sleep and feeding trends in intuitive charts.
- **PDF Reports**: Export 7-day summaries for your pediatrician.
- **Dark-First UI**: Optimized for one-handed use and night-time legibility.

## Getting Started
1. Clone the repository.
2. Open `baby-tracker.xcodeproj` in Xcode 15+.
3. Run on an iOS 17.0+ Simulator or device.

## Debugging
- Access the **Menu** tab to reset the onboarding flow (re-trigger registration).
- Use the **Settings** menu to "Delete All Data" if needed for a fresh start.
